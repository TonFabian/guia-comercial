# Sair & Tema Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Confirmar a saída da conta em modal e fazer o Perfil voltar a Visitante, além de proteger o default escuro do tema.

**Architecture:** O `AuthProvider` ganha `signOutToGuest`, que ativa o modo convidado antes de encerrar a sessão do Clerk. `ProfileScreen` abre um modal temático e chama essa ação; o tema é verificado por uma função pura testada.

**Tech Stack:** Expo SDK 58, React Native, Expo Router, Clerk, AsyncStorage, Vitest.

> **Sem commits nesta execução:** AGENTS.md proíbe commits sem pedido explícito.

```ts
async function confirmSignOut() {
  if (signingOut) return;
  setSigningOut(true);
  try {
    await signOutToGuest();
    setShowSignOut(false);
  } catch {
    Alert.alert('Sair', 'Não foi possível sair. Tente novamente.');
  } finally {
    setSigningOut(false);
  }
}
```

- [x] **Step 4: Render modal**

Renderizar `<SignOutModal visible={showSignOut} signingOut={signingOut}
onCancel={() => !signingOut && setShowSignOut(false)}
